# Codev 1.0.9

- 运行中的 Pi / Codex 线程会优先排到前面。
- 修复 Codex 压缩后的队列发送，以及末轮图片编辑和回车输入。
- Git 改为绑定工作区根目录；从文件树打开终端时会切到终端页。
- 多开视口改为手动加减格子，关闭内容不再拆掉窗口，并支持把搜索到的线程拖进视口。
- 新增可拖动的记事本，用来记录一次性待办和项目待办。

## 下载

- Codev-1.0.9-Windows-x64-Setup.exe
- Codev-1.0.9-Windows-x64-Portable.exe

Codex 功能需要本机安装 Codex CLI 并配置可用资源；Pi 功能需要安装 Pi Coding Agent。便携版与安装版保持独立应用标识。
