# Codev 1.0.7

- 新增 Git 仓库管理。设置中开启后，可在文件树旁选择仓库、暂存、提交、拉取、推送，并在主区打开差异和提交图。
- Pi 与 Codex 各自独立接入小米语音。配置互不影响，默认关闭。
- 新增默认关闭的右侧浏览器插件，支持多标签和刷新。开发窗口可打开独立检查元素；安装包和便携包不含网页检查工具。
- Pi / Codex 设置增加可选的回合文件感知。开启后，修改观测行显示增减行数，点击可在主区打开本回合差异。
- Pi 设置侧栏收敛为模型、技能、插件、通用；Codex 设置侧栏收敛为服务商存储和通用。
- 修复 Codex 资源档案读取。继续使用别名数组 `codev.json`，不再因旧格式报错。
- 修复 Pi 运行中发送消息直接消失的问题，待发送队列恢复为先排队、再按需插入。

## 后续修复与优化

- 新增默认开启的 Windows 任务栏待读角标，方便在切换应用后感知待查看的会话结果。
- Pi 输入框默认使用 high 思考级别，保留用户明确选择；运行时状态不再覆盖输入框的选择。
- Pi 模型资源配置与运行时应用状态分离，调整思考级别不再触发健康运行时重启。
- 修复 Pi 历史助手回复处的分叉位置：保留到所选回复所在轮次，移除后续对话；侧栏分叉和 `/fork` 继续复制完整会话。
- 修复 Pi 编辑最后一条输入后出现重复线程的问题，保持原线程身份。
- 修复 Pi 停止任务、编辑队列时图片丢失，以及旧队列协议兼容问题；队列按顺序投递，停止后保留未发送消息。
- 修复 Codex 插队消息确认后过早移除的问题，停止时可恢复尚未消费的输入。
- 优化 Pi 与 Codex 运行状态和过程条显示，过滤无关的 Pi 日志提示，避免结束后出现空过程条。
- 修复宽图片重复显示，恢复 Codex 回合修改观测的差异打开入口。
- 恢复 PDF 阅读、搜索链路及 HTML 预览右键刷新入口。
- 修复 Windows 无边框窗口四边拖拽缩放，以及切换应用、点击任务栏最小化再还原后左右侧栏意外折叠的问题。
- 终端、Pi、Codex 多视口关闭或切换布局时恢复正常分屏，避免残留放大状态造成空白界面。
- 多视口在宽度充足时优先使用三列；Pi、Codex 的三个视口可在宽屏下并排显示，终端同步适配宽屏四视口布局。
