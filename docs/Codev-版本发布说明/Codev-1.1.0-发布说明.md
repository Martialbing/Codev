# Codev 1.1.0

- Pi / Codex 输入技能改为行内 `$name`，发送和复制为带路径的短引用，不把技能全文塞进上下文。
- Pi 斜杠菜单保持原生，技能显示为 `/skill:name`，选中后写入 `$name`。
- 右键复制 Pi 对话里的图片时，复制图片本身，不再误复制周围文字。
- 切换 Pi / Codex 会话时保留阅读位置，不再跳到顶部或底部。

## 下载

- Codev-1.1.0-Windows-x64-Setup.exe
- Codev-1.1.0-Windows-x64-Portable.exe

Codex 功能需要本机安装 Codex CLI 并配置可用资源；Pi 功能需要安装 Pi Coding Agent。便携版与安装版保持独立应用标识。
