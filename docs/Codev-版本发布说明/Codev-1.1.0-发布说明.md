# Codev 1.1.0

- Pi / Codex 输入技能改为行内 `$name`，发送和复制为带路径的短引用，不把技能全文塞进上下文。
- Pi 斜杠菜单保持原生，技能显示为 `/skill:name`，选中后写入 `$name`。
- 右键复制 Pi 对话里的图片时，复制图片本身，不再误复制周围文字。
- 切换 Pi / Codex 会话时保留阅读位置，不再跳到顶部或底部。

## 增量修复（待审核）

- 文件树右键菜单新增“添加到 Pi 项目”和“添加到 Codex 项目”，支持添加文件夹或文件所在目录；已有项目直接复用，隐藏项目恢复显示，不影响已打开的会话。
- 记事本支持上下左右拉伸，面板随内容收紧，内容过多时在已保存高度内滚动，不再出现大块空白。
- 记事本底部输入默认一行，Enter 提交、Ctrl+Enter 换行；悬停预览显示在文字下方，右上角提供快捷键说明。

- Pi / Codex 输入框支持拖动顶部边缘调整高度，切换会话后恢复草稿的光标、选区和滚动位置。
- 修复长草稿拉高输入框后继续输入时，光标跳回旧位置的问题。
- 修复切回会话后输入框滚动到顶部的问题。
- 修复调整 Pi 阅读视口宽度时，部分消息相互重叠、出现残影的问题。
- 多视口区分清空内容和关闭当前格子；关闭后其余格子顺序补位，点击项目不再清空已有视口。
- Pi / Codex / 终端关闭到只剩一个视口时退出多视口模式；通过减号缩减仍可保留单格模式。
- 修复文件树恢复或导入工作区后，新增、删除文件和文件夹需要手动点击父目录才显示的问题。
- 删除已展开文件夹时同步更新父目录，并清理失效的子节点和展开状态；同名文件夹重新创建后仍能自动刷新。
- 修复 Pi 压缩后或分页历史回复无法分叉的问题；分叉保留选中轮次的完整工具过程，不带入后续轮次。
- 发送后自动收回已拉伸的输入框高度。
- 新收到的 Pi 回复若把思考写在正文开头的 `<think>` 标签里，会折叠进思考步骤，不再直接露在回复中。
