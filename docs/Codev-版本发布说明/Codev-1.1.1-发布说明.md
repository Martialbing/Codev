# Codev 1.1.1

审核状态：待人类审核。本文为本地构建说明，审核前不作为对外更新提示。

## 主题更新

- 第三套内置主题由 Catppuccin 替换为 Frosted Glass（玻璃感主题），支持浅色和深色模式。
- Windows 主窗口与设置窗口接入原生毛玻璃，并适配文件树、阅读区、代码编辑器、终端和插件面板的半透明背景。
- 调整原生玻璃合成方式，改善主窗口与设置窗口切换焦点时的材质变化；统一两者的原生圆角和窗口阴影。
- 使用中性乳白和烟灰底色，减弱壁纸及后方窗口色彩对界面的干扰，并保留背景透入效果。
- 浅色前端底色不透明度调整为 40%，深色为 55%，兼顾玻璃感与阅读清晰度。
- 深色模式下统一左侧文件树、中间主视口、右侧插件区域的透明度和颜色，所有区域直接透过窗口底色，避免雾蒙蒙的覆盖层。
- 优化窗口与面板的边缘高光和明暗层次，保留菜单、弹层的毛玻璃材质。
- 撤回搜索框、输入框、下拉选择框及选中按钮和标签新增的玻璃装饰，沿用原有控件设计。

## 多视口状态感知增强

- Pi Agent 和 Codex Agent 的多视口标题增加动态包络边框，运行时蓝色渐变边框从左向右滚动（1.2 秒循环），空闲时显示静态半透明边框。
- 标题字号优化为 10px，限制最大宽度 180px，为边框留出呼吸空间，垂直居中对齐。
- 边框颜色降低饱和度，与右侧运行状态指示器的蓝色风格保持一致。
- 运行状态包括：等待模型响应、工具调用中、停止请求中等，均显示滚动边框。
- 修复多视口下部分会话区高频闪动：已在底部附近不再反复写滚动位置，恢复循环加帧预算，滚动条占位固定。

## 交互修复

- 修复 Pi / Codex 侧栏右键「移到组」二级菜单被玻璃感父层裁切、点击无反应的问题。
- 修复视口标题进入重命名后每按一键都全选的问题。
- 修复无边框窗口从任务栏点回后变成一条细条、无法恢复的问题。

## 多视口标题拖换

- Pi Agent、Codex、终端和工作台支持按住视口标题拖到其他格子，交换内容且会话保持挂载。
- 双击标题仍可重命名；最大化或单视口时不可拖换。

## 编辑器语言包

- YAML、XML、SQL、Sass、Less 改用 CodeMirror 语言包，语法高亮与折叠更准确。

## 本地审核记录

- 审核热窗曾出现前端服务退出、原生窗口仍残留而无法加载的问题；新增独立 Windows 审核启动脚本，检查端口和编译冲突并保留启动日志。
- 本次在 1.1.1 上继续优化后重新生成安装包和便携包，并更新 GitHub Release 资源。
- 原生玻璃效果受 Windows 版本和透明效果设置影响；跨窗口焦点切换、圆角及透明度的最终观感仍以人类审核为准。
