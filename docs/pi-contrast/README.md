# Pi 会话区对比度改动：前后对照图

两张图都取自同一会话、同一主题（深色）、同一滚动位置，只替换了本次改动的样式，因此差异只来自改动本身。

| 文件 | 内容 |
| --- | --- |
| `pi-transcript-contrast.png` | 会话区整体（1.5x）：对话区底色、用户气泡、代码块、行内 code、工具摘要行 |
| `pi-tool-block-contrast.png` | 展开的工具块（1.9x）：工具命令等宽提亮、调用参数与执行结果降为 muted、左侧竖线缩进 |

## 读图要点

1. 左半（改动前）：对话区和面板同色，用户气泡是无边界灰块，代码块用 `bg-background` 只剩上下两条细线，行内 code 比气泡更亮。
2. 右半（改动后）：对话区比面板亮约 5%，用户气泡 `9%` 底 + 1px 细边，代码块 `5%` 底 + 边线，行内 code 与气泡同层。
3. 工具块：改动前参数和输出与正文一样亮；改动后命令保持最亮（等宽），参数与输出降到第二层，展开体有左侧竖线和缩进。

详细改动与验证见 PR 描述。
